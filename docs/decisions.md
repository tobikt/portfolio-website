# Architecture Decision Records (ADR)

## [ADR-001] Framework & Sprache
**Status:** Akzeptiert
**Entscheidung:** Angular & TypeScript
**Begründung:** Komponente-basierte Architektur, starke Typsicherheit und Skalierbarkeit für zukünftige Erweiterungen.

## [ADR-002] Dokumentations-Standard
**Status:** Akzeptiert
**Entscheidung:** Alle Planungen, Diskussionen und Entscheidungen werden in Markdown (.md) Dateien im Verzeichnis `docs/` dokumentiert.
**Begründung:** Versionierbarkeit der Dokumentation im Git-Repository und einfache Lesbarkeit.
