# Cloud Software Architect mit Automotive- und Engineering-Hintergrund

Ich entwickle Software und Cloud-Architekturen, die nicht nur im Demo-Fall funktionieren, sondern im Projektalltag wartbar bleiben: klare Schnittstellen, reproduzierbare Infrastruktur, nachvollziehbare Entscheidungen und ein realistischer Blick auf Betrieb.

Mein Schwerpunkt liegt zwischen AWS, Infrastructure as Code, Automotive Software und technischer Anwendungsentwicklung. Ich übersetze Anforderungen in Strukturen, mit denen Teams weiterarbeiten können — ohne unnötige Komplexität und ohne Architektur als Selbstzweck.

- AWS Cloud Architecture und Infrastructure as Code
- Software Engineering, Microservices und API Design
- Automotive, Embedded-Umfeld und technische Toolchains
- Dokumentation, Qualitätssicherung und teamfähige Umsetzung
